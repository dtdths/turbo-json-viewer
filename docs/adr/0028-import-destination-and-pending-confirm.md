# ADR-0028：导入落点（默认新标签 + 完整层 radio）与「精简确认层」（拖入正文 / ⌘V）

- 状态：**Implemented**（2026-11-18；实现票 #51）
- 日期：2026-11-18
- 依据：ADR-0004（导入层语义 / `⌘V` 契约）、ADR-0009 §4–§5（多标签 / 拖放按落点）、ADR-0011（设置持久化）、ADR-0016（空态视觉规格）、#47（需求批次拍板）
- 相关票：#47（批次）、#51（本 ADR 的实现票）

## 背景

1. **导入默认落点是「替换当前文档」**：多标签工作区（ADR-0009）已经支持新标签，但用户每次都得在入口层里点一下文字链接切换。用户 2026-11-18 要求「默认在新标签导入，并给设置项」；同时**入口层里那个文字链接不够显式**，应改成 switch/radio。
2. **文档视图内 `⌘V` 被完全忽略**（ADR-0004 的 Q5-A 契约：层关闭时不处理、不 `preventDefault`）。用户要求：在看文档时粘贴 → 提示「是否在当前页导入粘贴数据」，确认且数据合法才覆盖。
3. 拖入文档正文目前开的是**完整导入层**（带 dropzone / 切换链接 + 暂存的「替换当前文档」按钮），对一个「已经拿到数据、只差选落点」的确认动作来说太重。

## 决策

### 1. 完整导入层的落点 = 显式 radio，默认值来自新设置项

- `#emptyModeToggle`（文字链接）→ **两个 radio**「新标签 / 替换当前」（`role=radiogroup`、原生 `input[type=radio]`）；完整层打开时按设置选中，改动**只对本次导入生效**（不写设置）。
- 新设置项 **`importTarget`**（设置面板「导入位置」，默认 **`new-tab`**）：只决定完整层（⌘O / 导入按钮 / 文件 chip）打开时的初始选中项。
- 拖放仍**按落点**（ADR-0009 §5 不变）；但拖到文档正文不再开完整层，而是走下面的精简确认层。
- **标签满 8**：完整层默认新标签时**自动降为「替换」**，并在层里显示一行说明（显式请求新标签则 toast 拒绝，不静默改落点）。
- 初始空态（还没有文档）不显示 radio——两个选项当时没有区别。

### 2. 精简确认层（`data-mode="pending"`）：只回答「落到哪」

- 触发：**拖入文档正文** / **文档视图内 ⌘V**（含原文视图、表达式结果视图）。
- 内容：标题 + `待导入：<b>名称（大小）</b>` + 两个按钮「在新标签打开 / 覆盖当前页」+ 取消；**无 dropzone、无 radio、无覆盖警示**。
- 焦点落「在新标签打开」（非破坏性）；标签满 8 时该按钮**禁用**（`title` 说明）并把焦点让给「覆盖当前页」。
- 解析失败：**留在层内显示错误**，当前文档不动（复用入口层错误区）。
- 选择「覆盖当前页」前若当前文档有未导出修改，先走既有 `confirmDiscardEdits`。
- 表达式结果视图里确认后：先回文档树，再替换当前文档（`onLoaded` 既有行为）。
- 结构上复用 `#empty` 层 DOM + 一套遮罩/焦点管理，新增 `data-mode="pending"` 变体，不新造模态组件。
- 粘贴仍只处理 `text/plain`（**粘文件不支持**，记为已知差距；`importBuffer` 的 `source:'clipboard'` 仍为死值）。

## 被否决的替代

| 方案 | 否决理由 |
| --- | --- |
| 保留文字链接、只改默认值 | 用户明确「那个选项应改为 switch/radio」；链接态不可见（用户不知道有第二个落点） |
| `window.confirm` 做粘贴确认 | 无法承载「解析失败留在层内、当前文档不动」；且与拖放路径分裂成两套确认 |
| 拖正文也开完整层 | 多一个 dropzone 与 radio，却没有新增信息；确认层更短 |
| 设置管拖放落点 | 拖动位置本身就是意图（ADR-0009 §5 不变） |
| radio 改动写回设置 | 一次临时替换会永久改默认，用户找不到原因 |

## 后果

- **ADR-0004 的 Q5-A 契约被修订**：文档已打开且层关闭时，页面级 `⌘V` 不再忽略，而是打开精简确认层（`preventDefault` + 确认后才导入）。ADR-0004 / ADR-0009 §5 的相关表述已同步。
- 设置面板从 14 行变 **15 行**（「导入位置」插在语言之前，语言仍殿后）。
- 拖放的两条落点路径收敛：标签条空白 = 直接新标签；文档正文 = 精简确认层；完整层内拖放 = 「层内即确认」不变。
