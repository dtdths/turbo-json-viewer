Privacy Policy — Turbo JSON Viewer

A local JSON viewer. Your documents never leave your computer.

Effective 2026-11-23 · applies to Turbo JSON Viewer 0.1.x (Chrome extension) · 中文版见下

Short version

Turbo JSON Viewer does not collect, transmit, sell or share any personal data. There is no account, no analytics, no telemetry and no network access. JSON you open is parsed and rendered in memory on your own device.

What the extension processes

The extension processes the JSON you choose to open (pasted, dropped, picked from disk, or sent from the right-click menu) and the interface preferences you change. Processing happens entirely inside the extension page and its background worker on your machine. The extension makes no outbound requests: it has no servers, no remote endpoints and loads no remote code.

What is stored, and where

DataWhereWhy
Interface preferences (theme, language, indentation, import destination, export mode, and other viewer settings) chrome.storage.local on this device So your settings survive a page reload
Document content (the JSON you open) Memory only — never written to storage or disk To render, search and filter it
Selected text you send from the right-click menu One-time chrome.storage.session entry, deleted as soon as the viewer opens it To hand the selection to the viewer tab

Uninstalling the extension removes its local storage. Because documents are never persisted, there is no stored copy of your data to delete beyond the preferences above.

Permissions and why they exist

  • storage — remembers interface preferences locally. It is not used to store documents.
  • contextMenus — adds a single right-click submenu (“Open in viewer” / “Download JSON”) for text you have selected. The extension does not read page content on its own, does not inject scripts, and requests no host permissions (no “read and change all your data on websites”).

Data sharing

None. No data is sold, transferred or disclosed to third parties, and none is used for advertising, profiling, or creditworthiness decisions. The extension has no third-party SDKs and no remote code.

Children and sensitive data

The extension is a developer utility with no user accounts and no data collection. It is not directed at children, and there is nothing to opt out of.

Changes

If this policy changes, the updated version will be published at this URL with a new effective date. Any change that affects what is processed will also be noted in the extension’s release notes.

Contact

Questions or concerns: open an issue at github.com/dtdths/turbo-json-viewer/issues.

隐私政策 — Turbo JSON Viewer

本地 JSON 查看器。你的文档不会离开这台电脑。

生效日期 2026-11-23 · 适用于 Turbo JSON Viewer 0.1.x（Chrome 扩展）

一句话

Turbo JSON Viewer 不收集、不上传、不出售、不共享任何个人数据。没有账号、没有统计、没有遥测， 也不发起任何网络请求。你打开的 JSON 只在本机内存中解析与渲染。

扩展处理哪些数据

扩展处理你主动打开的 JSON（粘贴、拖放、从磁盘选择，或经右键菜单送入），以及你修改的界面偏好。 处理全部发生在你机器上的扩展页面与后台 Worker 内。扩展没有服务器、没有远端接口，也不加载任何远程代码。

存了什么，存在哪

数据位置用途
界面偏好（主题、语言、缩进、导入落点、导出方式等查看设置） 本机的 chrome.storage.local 刷新页面后仍保留你的设置
文档内容（你打开的 JSON） 仅内存——从不写入 storage 或磁盘 用于渲染、搜索与过滤
你从右键菜单送出的选中文本 chrome.storage.session 的一次性条目，查看器读取后立即删除 把选区交给查看器标签页

卸载扩展会清除它的本地存储。由于文档从不持久化，除上述偏好外没有留存的数据副本需要删除。

权限与用途

  • storage — 在本地记住界面偏好；不用于存储文档。
  • contextMenus — 为你选中的文本增加一个右键子菜单（「在查看器中打开」/「下载 JSON」）。 扩展不会自行读取网页内容、不注入脚本，也不申请任何 host 权限（没有「读取和更改你在网站上的所有数据」）。

数据共享

没有任何共享。数据不出售、不转交、不披露给第三方，也不用于广告、画像或信用评估。 扩展不含第三方 SDK，也不加载远程代码。

未成年人 / 敏感数据

本扩展是开发者工具，没有账号体系，也不收集数据；不面向未成年人，也没有需要退出的选项。

政策变更

若政策变更，更新版本会发布在同一 URL 并标注新的生效日期；涉及处理方式的变化也会写进版本说明。

联系方式

问题或疑虑：请在 github.com/dtdths/turbo-json-viewer/issues 提 issue。
