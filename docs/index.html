Turbo JSON Viewer

A fast, fully local JSON viewer for large files — worker-resident parsing, search, JS expressions and temporary edits. Nothing is uploaded.

Chrome extension (Manifest V3) · v0.1.0 · Chrome 120+ · source on GitHub · 中文版见下

Not on the Chrome Web Store yet. The developer account registration is still being sorted out, so there is no store link for the moment.

The unpacked build in the repository is complete and testable — see Install now.

What it does

  • Opens big documents. Documents live in a background worker; the page only ever holds the rows on screen, so a 50 MB file does not lock up the tab.
  • Finds things. Search keys, values and JSON paths — case-sensitive, regular expression and whole-word modes, with hit filtering and jumping.
  • Queries with expressions. Filter or project with a JavaScript subset such as $.orders.filter(o => o.total > 100), evaluated by a built-in interpreter — no eval, no remote code.
  • Shows structure and source. An outline panel for navigation, plus a raw source view with two-way jumps between tree and text.
  • Handles several documents. Up to 8 documents in tabs, each keeping its own selection, scroll position and search.
  • Edits nothing on disk. Subtree edits are temporary and in-memory; export and copy go through a Save dialog you control, with big integers preserved.

Built for large files

MeasuredResult
First paint, 10 MB file~0.11 s
First paint, 50 MB / ~3M nodes~0.61 s

Measured on the development machine with the unpacked extension in Chrome for Testing 156; your numbers depend on hardware and document shape.

Privacy

  • No network access. No servers, no remote endpoints, no remote code, no analytics, no telemetry.
  • Documents never leave the device. They are parsed and rendered in memory and never written to storage or disk.
  • Two permissions. storage for your interface preferences, and a contextMenus submenu for text you select. No host permissions, no page injection.

The full policy is at Privacy Policy.

Install now (unpacked)

  1. Build the extension: 
    git clone https://github.com/dtdths/turbo-json-viewer.git
cd turbo-json-viewer
npm install
npm run build
  2. Open chrome://extensions, turn on Developer mode, click Load unpacked and select the dist/ folder.
  3. Click the toolbar icon to open the viewer, then drop a .json file onto the page or paste JSON with ⌘V / Ctrl+V.

它能做什么

  • 打得开大文件。 文档常驻后台 Worker，页面只持有屏幕上那几行，50MB 的文件不会把标签页卡死。
  • 找得到东西。 搜索键名、值与 JSON 路径——支持区分大小写、正则与全词匹配，可过滤命中并在命中间跳转。
  • 用表达式查。 用 JavaScript 子集过滤或投影，例如 $.orders.filter(o => o.total > 100)，由内置解释器执行——不用 eval，不加载远程代码。
  • 结构与原文都在。 大纲面板用于结构导航，原文视图支持树与文本双向跳转。
  • 多文档并存。 最多 8 个文档标签，各自保留选中行、滚动位置与搜索态。
  • 不碰你的文件。 子树编辑是内存里的临时稿；导出与复制走你自己控制的保存对话框，大整数不丢精度。

隐私

  • 没有网络访问。 没有服务器、没有远端接口、没有远程代码，也没有统计与遥测。
  • 文档不出这台机器。 只在内存中解析与渲染，从不写入 storage 或磁盘。
  • 只有两个权限。 storage 存界面偏好，contextMenus 为你选中的文本加一个右键子菜单；没有任何 host 权限，不向网页注入脚本。
