04

边框负责结构，阴影只负责“浮起来”。除弹层与 JSON 地图外，几乎不使用大阴影；发光只给主按钮。

05

行解剖

树行是产品的核心像素：24px 高、16px 一级缩进、折叠容器保留可读预览。选中态用低透明靛蓝，不夺走类型色。

  1. 1缩进引导线每级 16px，1px --border-subtle；深度可一眼数清。
  2. 2折叠箭头11px chevron，展开旋转 90°；标量行隐藏占位保持对齐。
  3. 3键名冷灰蓝；数组下标与数字键改用更暗的 --syntax-index。
  4. 4值 / 类型色字符串青绿、数字琥珀、布尔紫、null 灰；颜色之外仍有文本差异。
  5. 5计数数组 [12]、对象「8 项」；折叠时保留首字段预览。
  6. 6折叠预览一行内给出 2–3 个字段，减少无谓展开；长内容省略。
  7. 7操作hover 出现复制 / 编辑浮条；选中行内联常显，避免被 JSON 地图遮挡。
  8. 8搜索命中暖黄底 + 内描边，叠加在类型色之上，不替换类型信息。

选中行：--bg-selected（靛蓝 14%）+ 2px 左条；同一节点在状态栏路径与 JSON 地图中同步高亮。省略行用斜体 + faint，明确「还有内容但未展开」。

构成

  • 头部标题 / 深度徽标 / 折叠按钮；面板 264 × 204，圆角 10、shadow-lg。
  • 层级塔每层一行 20px；数组追加 [1234/5000]；连接线 1px border。

  • 无障碍Canvas aria-hidden，底部等价文本面包屑并 aria-live="polite"。
