VISUAL DIRECTION 02 / SLATE

Slate / VS Code

冷蓝灰的 IDE 骨架，为「本地、极速、只读」的 JSON 工作台服务。没有渐变装饰，也没有模板感的卡片堆叠： 边界全部交给 1px 冷灰线，蓝色只留给动作与焦点，数据本身由 VS Code 语义色说话。 26px 行高换来一屏约 29 行；右下角 260×200 的 Canvas 层级塔让「现在在哪一层」始终可见。

深色默认 · 亮色完整 48px 活动栏 26px 行高 Canvas 层级塔 零外部请求 1440×900 / 1280×720

评审看这 5 点

  1. 01深色下是否像专业 IDE，而不是「黑色仪表盘」？
  2. 0226px 行高 + 12.5px 等宽的密度，在 1440 与 1280 两档是否都可读？
  3. 03蓝色是否只出现在动作、选中、焦点上，没有抢走数据配色？
  4. 04JSON 地图的层级塔 + 同级刻度，能否一眼看出层级与位置？
  5. 05亮色是重新调过对比与阴影，还是简单反色？
01

色板与语义

底色是冷蓝灰（#0F1115 → #151922 → #1B202B），越靠前的平面越深；文字用 #D7DEEA 而不是纯白，避免长时阅读的眩光。语义色只用于语法与状态，不用于布局装饰。

JSON 地图 · Canvas 层级塔

260×200 常驻右下角，跟随选中节点。每层显示 key、类型点、[i/N]；当前节点用 accent 底 + 左条 + ◉；当前层的兄弟用刻度尺呈现（±2），下方用一条全局位置轨道表示 4 / 10。

读法与规则

  • 层级塔：只画根 → 当前的祖先链（O(depth)），不画全文档。
  • 当前位置：当前行 accent 底 + 2px 左条 + 右侧 ◉；[1234/5000] 表示它是第几个子项。
  • 兄弟刻度：当前层前后各 2 个 key；全局轨道上的蓝点表示 4 / 10。
  • 折叠态：收成 40×40 地图按钮，状态记录在视图状态里。
  • 无障碍：Canvas aria-hidden，面板下方提供等价文本 breadcrumb，并配 aria-live 路径播报。

交付与检查 review checklist

  • index.html 支持 ?screen=main|empty|edit|expr|search 与 &theme=dark|light；修复态用 ?screen=main&repair=1。
  • 两个页面都是自包含单文件：无 CDN、无图片外链、无字体请求、无控制台错误。
  • 所有图标为内联 SVG；JSON 地图为 Canvas，DPR 适配，主题切换后重绘。
  • 1440×900 完整呈现；1280×720 下工具栏收成图标、地图走道收窄，仍可读。
  • 键盘：可见 focus ring、Esc 关闭弹层/抽屉、行操作有 aria-label。
