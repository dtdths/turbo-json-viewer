# 方向 C · 工作台 — Turbo JSON Viewer 视觉原型

> **在 A 的视觉语言之上，吸收 B 的活动栏与双侧工作区。**
> `prototype/visual/c/` 只是叠加层：token 与组件来自 `../a/tokens.css`、`../a/app.css`，
> `../a/app.js` 继续驱动屏幕切换、树渲染、搜索结果、主题与 JSON 地图；本目录只有 `c.css` / `c.js`。

## 1. 与 A / B 的关系

| | A | B | **C** |
|---|---|---|---|
| 视觉语言 | Graphite / Indigo | Slate / VS Code | **A 的**（24px 行、靛蓝焦点、单层工具栏、24px 行高） |
| 活动栏 | 无 | 左侧 48px | **左侧 48px**（文档 / 搜索 / 大纲 / 表达式 / 主题 / 设置） |
| JSON 视图 | 占满宽度 | 占满（右侧留地图走道） | **中间列，左右各让出面板** |
| 搜索 | 顶部搜索框 + 右侧 330px 结果栏 | 左侧 304px 搜索视图 | **左侧面板 320px**（查询 + 结果 + 过滤） |
| JSON 地图 | 右下浮层 | 右侧走道内浮层 | **右侧工作区顶部模块** |
| 右侧内容 | 地图 | 地图 | **地图 + 选中节点 + 文档概要 + 临时修改** |

## 2. 布局

```
┌ 活动栏 48 ┬ 工具栏 48（品牌 / 文件 / 导入 / 导出 / 右侧栏）──────────────────────────────┐
│ 文档       ├ 修复提示条 32（仅修复文档）───────────────────────────────────────────────┤
│ 搜索       │ ┌ 左侧面板 320 ─┐ ┌ 树（max 1280px，居中）─────────┐ ┌ 工作区 300 ─────┐ │
│ 大纲       │ │ 搜索/大纲/设置 │ │ 24px 固定行高 · 单行省略        │ │ JSON 地图       │ │
│ 表达式     │ │                │ │ 深层横向滚动                    │ │ 选中节点(换行)  │ │
│            │ └────────────────┘ └─────────────────────────────────┘ │ 文档概要        │ │
│ 主题       │                                                         │ 临时修改        │ │
│ 设置       │                                                         └─────────────────┘ │
├────────────┴ 状态栏 26（节点 / 行 / 大小 / 路径 / 本地）───────────────────────────────┤
```

- **一个命令只有一个家**（见 §2.1）：活动栏管「视图/模式」，工具栏管「文档动作」；
  搜索、表达式、主题、设置只在活动栏出现，工具栏不再重复。
- 左面板按活动栏切换：文档（关闭）/ 搜索 / 大纲 / 设置；表达式仍是底部抽屉。
- 右工作区可整体折叠（工具栏「右侧栏」按钮或面板右上角箭头），折叠后树拿到全部宽度。

### 2.1 命令归属

| 位置 | 放什么 | 理由 |
|---|---|---|
| 活动栏（左） | 文档树 · 搜索 · 大纲 · 表达式（模式，带激活态）；底部 主题 · 设置 | 有「当前处于哪个工作视图」的状态，属于模式切换 |
| 工具栏（顶） | 品牌 · 文件 chip · 临时修改徽标 · 导入 · 导出 · 右侧栏开关 | 无状态的文档级/全局动作，跟当前视图无关 |

右侧栏开关在工具栏与面板头各有一个：面板折叠后头部按钮不可见，必须留工具栏入口才能展开。
- 空态不显示工作台；状态栏固定在底部。

## 3. 为什么右侧放这些

| 模块 | 为什么常驻右侧 | 数据来源 |
|---|---|---|
| JSON 地图 | 跟随选中节点的层级塔，是深树导航的“我在哪” | `docs/design/json-map-spec.md`（v1.1） |
| 选中节点 | **长值换行的唯一位置**：树内单行省略，完整值在这里换行 + 可复制/编辑 | 当前值图 |
| 文档概要 | 一眼回答“这份文档长什么样”：节点/容器/深度/类型分布 | Document Profile 采样 |
| 临时修改 | 暴露 undo 栈，避免“改了忘了 / 不知道改了哪” | ADR-0006 编辑历史 |

候选（尚未放入原型，避免拥挤）：表达式结果根列表（LRU 3）、复制格式面板、类型/键过滤、最近搜索。

## 4. 关于「字段值太长要不要换行」

**树行不换行**，这是硬约束：

- 行窗口协议按**固定行高**取值（`docs/adr/0001`），滚动条映射 `contentPx = totalRows × rowH`；
  允许换行 = 行高可变 = 需要逐行测量 + 高度缓存 + 可变高度滚动映射，等于推翻行模型。
- 50MB 全展开 2,958,550 行；可变行高下每行测量成本会直接吃掉“首帧 150ms”的预算。

C 的处理：树内保持单行省略（现在 `--row-preview` 已有 620px 上限），**完整值在右侧「选中节点」面板换行显示**；
需要编辑时走子树 JSON 编辑弹层。深层嵌套靠地图 + 大纲 + 横向滚动解决，不靠换行。

## 5. 如何打开

```bash
node prototype/visual/serve.mjs
# http://127.0.0.1:5199/compare.html   ← A / A+类型列 / B / C 实时切换
```

C 的 URL 状态：

| 状态 | URL |
|---|---|
| 主界面 | `c/index.html?screen=main&theme=dark` |
| 搜索（左面板） | `c/index.html?screen=search&theme=dark` |
| 大纲 | `c/index.html?screen=main&panel=outline&theme=dark` |
| 设置 | `c/index.html?screen=main&panel=settings&theme=dark` |
| 折叠右侧栏 | `c/index.html?screen=main&rail=0&theme=dark` |
| 表达式抽屉 | `c/index.html?screen=expr&theme=dark` |
| 子树编辑 | `c/index.html?screen=edit&theme=dark` |
| 亮色 | 任意 URL 加 `&theme=light` |
| 类型列（继承 A） | 任意 URL 加 `&typecol=1` |

截图：`node prototype/visual/shoot.mjs c` → `prototype/visual/shots/c-*.png`。

## 6. 状态

- 纯视觉原型，不解析 JSON、不虚拟化、不接 Worker；数据是硬编码演示值。
- 交互可用：活动栏切换面板、右栏折叠、主题、搜索结果上下条、地图（真实 Canvas 绘制）。
- 待定：左侧面板默认是否展开、右栏 4 个模块的取舍、深层缩进是否提供 12px 选项。
